# Cloud Native DevOps Beginner Project

## Project Goal
Build a beginner-friendly DevOps project by learning and implementing concepts step by step.

## Tools Used
- Linux
- Git & GitHub
- Docker
- Kubernetes (Minikube)
- GitHub Actions

## Learning Approach
Learning while doing – each module adds new DevOps skills.

## Modules
- Module 0: Project Setup & Concepts
- Module 1: Linux Basics
- Module 2: Git & GitHub
- Module 3: Simple Application
- Module 4: Docker
- Module 5: CI Pipeline
- Module 6: Kubernetes
